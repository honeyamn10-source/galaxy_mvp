03 / Run it yourself

Start from the source.

Docker with Compose, GNU Make and Python. Review service configuration in docker-compose.yml before starting.

Clone the repository, then use the commands below. Review the README before connecting external services.

SOURCE CHECKOUT
git clone https://github.com/honeyamn10-source/galaxy_mvp.git
cd galaxy_mvp
make setup
make swarm-up
make health
make test
