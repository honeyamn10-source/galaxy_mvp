Architecture

galaxy_mvp follows a layered microservices architecture with clear separation of concerns.

Authority Chain

Consensus, governance, and access control. Manages permissions across the network.

Auth Service

Authentication and identity management. OAuth2, JWT, decentralized identifiers.

Intelligence Layer

LLM service, model registry, inference endpoints. Supports multiple model providers.

Economic Layer

Tokenomics, rewards, staking. Incentivizes participation and resource contribution.

Expansion Layer

Plugin system for extending capabilities. Dynamic service discovery.

Edge Planet

Edge computing nodes. Camera integration, live processing, local inference.
